### How to handle exceptions

- try:
  - The code that is being tested for exceptions.
- except:
  - The code that is executed if an exception is caught.
- else:
  - The code that is executed if no exception is caught.
- finally:
  - The code that is executed no matter what.

### Syntax for handling exceptions

```python
try:
    # Code that is being tested for exceptions.
except:
    # Code that is executed if an exception is caught.
else:
    # Code that is executed if no exception is caught.
finally:
    # Code that is executed no matter what.
```

#### Example of try, except, else, and finally

```python
try:
    num1 = int(input("Enter a number: "))
    num2 = int(input("Enter a number: "))
    result = num1 / num2
    print(result)
except ZeroDivisionError:
    print("Cannot divide by zero")
except ValueError:
    print("Invalid input")
else:
    print("Division successful")
finally:
    print("End of program")
```

#### Example of re-raising an exception with custom message

- Reraise with different type
- Reraise with more specific message

```python
def divide(num1, num2):
    try:
        result = num1 / num2
        print(result)
    except ZeroDivisionError:
        raise Exception("Cannot divide by zero")  # Re-raises the exception with custom message

try:
    divide(10, 0)
except ZeroDivisionError:
    print("Division by zero error handled")
```

5. The advantages and disadvantages of lists and tuples
    - **Lists:**
        - **Advantages:** Mutable (can be modified), flexible for dynamic data, extensive built-in methods (append, sort, etc.).
        - **Disadvantages:** Slower performance and higher memory usage than tuples; less safe from accidental modification.
    - **Tuples:**
        - **Advantages:** Faster performance, lower memory usage, immutable (data safety), can be used as dictionary keys.
        - **Disadvantages:** Inflexible (cannot be changed after creation), fewer built-in methods.
